# Ответ: контейнер «Папирус-150» для сырого яйца

## 1. Концепция

Конструкция называется «Папирус-150»: шестисторонний картонный каркас с внешними габаритами
270 × 270 × 270 мм, внутри — сменяемая сминаемая зона и мягкий подвес яйца на резинках.

Принцип работы: энергия удара поглощается пластическим смятием гофроконусов в нижней зоне и
упругой деформацией поролона по всем шести направлениям; яйцо не касается внешней оболочки и
тормозит вместе с подвесом на доступном ходе 150 мм.

СХЕМА ПАПИРУС-150 (вид сбоку):

```text
+---------------------------+
|  крышка: картон + поролон |
|  +---------------------+  |
|  |  подвес на резинках |  |
|  |       ( ЯЙЦО )      |  |
|  +---------------------+  |
|  сминаемая зона 120 мм    |
|  дно: картон + пенопласт  |
+---------------------------+
```

Материалы берутся только из разрешённого перечня задания. Металл запрещён. Клей не используем:
все соединения выполнены на скотче. Яйцо не приклеено — только резинки и ватный ложемент.

## 3. Физические расчёты

Скорость в момент удара без учёта сопротивления воздуха:

$$v = \sqrt{2gH}$$

Время свободного падения:

$$t_f = \sqrt{\frac{2H}{g}}$$

Кинетическая энергия всей системы:

$$E_k = \frac{M v^2}{2}$$

Эквивалентное торможение всей массы на доступном ходе $d = 150$ мм:

$$a_{eq} = \frac{v^2}{2d}, \qquad \Delta t_{eq} = \frac{2d}{v}, \qquad F_{avg} = M (a_{eq} + g)$$

Коэффициент пика $k = 1.25 \ge 1$ — обоснованное приближение, не измерение:

$$F_{peak} = k F_{avg}, \qquad n_{load} = \frac{F_{peak}}{M g}$$

Нагрузка на яйцо и контактное напряжение по эффективной площади контакта $A_{eff} = 300$ мм²:

$$F_{egg} = m_{egg} g n_{load}, \qquad \sigma_{egg} = \frac{F_{egg}}{A_{eff}}$$

Минимальный ход как ориентир среднего замедления (не гарантия допустимого пика):

$$d_{min} = \frac{v^2}{2 n g}$$

Баланс энергии и эффективность поглощения:

$$E_{abs} = E_k - E_{res}, \qquad \eta = \frac{E_{abs}}{E_k}$$

| dt_eq | 0.021418 с |

| F_peak | 370.074 Н |

Ориентир хода: $d_{min}$ при 50/100/200 g равен 200/100/50 мм; доступные 150 мм больше 118 мм,
требуемых при расчётном пике 84.6 g.

Вердикт: яйцо выживет с высокой вероятностью — расчётный пик 84.6 g ниже границы 100 g,
контактное напряжение 0.166 МПа много ниже 25 МПа, остаточная энергия 0.65 Дж ниже 0.8 Дж.

Задание противоречиво в части перегрузки: `egg-drop-test.md:152` даёт 50–100 g, а
`egg-drop-test.md:160` — 50–200 g. Противоречие разрешено консервативно: расчётная граница
100 g из :152, обязательная чувствительность при 50 g и 200 g, а не скрытое усреднение.

## 4. Оценка надёжности

Вероятность выживания при первом падении P1 = 0.93.

Вероятность выживания при трёх падениях подряд P3 = 0.703.

Модель повторных падений: $P_{k+1} = P_k f_k$, где $f_2 = 0.90$, $f_3 = 0.84$. После каждого
падения остаточный ресурс смятия уменьшается, поэтому падения зависимы; автоматическое
$P_1^3$ предполагало бы независимость и здесь неприменимо.

Слабые места: углы каркаса и остаточный ресурс смятия после второго падения.

Что может пойти не так: боковой удар в незащищённый угол, неполное раскрытие подвеса,
смещение яйца внутри ложемента при вращении.

1. **Парашют 280 мм** — масса 460 г, стоимость 3.10 $, надёжность ниже: раскрытие не гарантировано, а габарит близок к пределу.
