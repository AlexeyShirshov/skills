# Работа с PDCA

[English](../../guide/README.md)

Этот раздел для тех, кто поручает задачи агенту и хочет знать, что именно тот сделал и чем это подтверждается. Опишите нужный результат, а не порядок фаз. Назовите `pdca` явно; если задача не требует цикла, поручите её напрямую.

Для первого запуска читайте по порядку. Если уже пользовались PDCA, выберите нужную страницу:

1. [Запустите первый цикл](first-cycle.md). Установите скиллы, отправьте запрос, одобрите план и проверьте результат.
2. [Разберитесь, какую форму выберет PDCA](choose-a-form.md). Отличите одну ограниченную задачу, кампанию и пакет независимых целей.
3. [Управляйте запуском и возобновляйте работу](control-a-run.md). Выберите режим и продолжите с сохранённого состояния.
4. [Прочитайте результат](read-the-result.md). Найдите критерии, доказательства и границы вердикта.
5. [Скопируйте промпт](recipes.md). Запустите исправление бага, .NET-задачу, кампанию или коллекцию.

Правила фаз и полномочия ролей описаны в [техническом путеводителе](../pdca-guide.md), настройка среды — в [инструкции по установке](../install.md).
