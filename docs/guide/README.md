# Use PDCA

[Русский](../ru/guide/README.md)

Use this guide if you work with an agent and want to know what it delivered and what proves it. Give the agent a result, not a list of phases to run. Ask for `pdca` explicitly; for ordinary work that doesn't need the cycle, ask for the task directly.

Read the pages in order on your first run, or start with the task you need:

1. [Run your first cycle](first-cycle.md). Install, send a prompt, approve the plan, and inspect the result.
2. [Understand which form PDCA picks](choose-a-form.md). Distinguish one bounded task, one campaign, and a batch of independent goals.
3. [Control and resume a run](control-a-run.md). Choose who approves the plan and continue from recorded state.
4. [Read the result](read-the-result.md). Find the criterion, the proof, and the limits of the verdict.
5. [Copy a prompt](recipes.md). Start a bug fix, .NET change, campaign, or collection.

For phase rules and role boundaries, see the [technical guide](../pdca-guide.md). For setup by host, see [installation](../install.md).
